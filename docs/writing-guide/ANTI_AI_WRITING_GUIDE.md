## 一、什么是"AI 味"？

AI 生成文字的典型特征包括：

1. **过度使用过渡词**：值得注意的是、综上所述、客观来说
2. **模糊程度副词**：在一定程度上、某种程度上、相对而言
3. **空洞开头**：近年来、随着时代发展、在当今社会
4. **无力结论**：可能存在一定影响、有待进一步研究
5. **废话句式**：首先，我们需要……、本文采用XX方法
6. **堆砌形容词**：非常重要的、具有重大意义的
7. **被动句过度**：已经被证实、可以被认为
8. **中英混杂**：无故在中文中插入英文术语

这些句式会让论文显得机械、缺乏深度、底气不足。

## 二、AI 典型句式替换表（20+组）

### 2.1 过渡套话类

| AI 典型句式（禁止） | 替代表达（推荐） |
|---------------------|-------------------|
| "值得注意的是" | 直接说发现，不加铺垫 |
| "综上所述" | 改为"具体而言"或直接分段 |
| "客观来说" | 删除，或改为"从数据看" |
| "从某种意义上说" | 删除，或改为具体说明 |
| "一般而言" | 删除，或改为"在全样本中" |
| "总体上看" | 改为"从均值来看"或"回归结果显示" |

### 2.2 模糊程度类

| AI 典型句式（禁止） | 替代表达（推荐） |
|---------------------|-------------------|
| "在一定程度上" | 删除，或改为"实证上" |
| "某种程度上" | 删除，或改为"主要通过" |
| "相对而言" | 改为"具体而言"或删除 |
| "可能存在一定" | 删除"可能"和"一定"，直接说结论 |
| "大致相同" | 改为"相近"或"无显著差异" |
| "基本一致" | 改为"在统计上无显著差异" |

### 2.3 空洞开头类

| AI 典型句式（禁止） | 替代表达（推荐） |
|---------------------|-------------------|
| "近年来" | 改为具体年份或具体事件 |
| "随着时代发展" | 删除，直接从研究背景切入 |
| "在当今社会" | 删除，直接说现象或问题 |
| "随着经济的快速发展" | 改为具体数据或具体政策 |
| "在新时代背景下" | 删除，直接说政策或事件 |
| "在此背景下" | 删除，直接说研究发现 |

### 2.4 无力结论类

| AI 典型句式（禁止） | 替代表达（推荐） |
|---------------------|-------------------|
| "可能存在一定影响" | "显著提升/下降了 X%（β = 0.XX, p < 0.01）" |
| "有待进一步研究" | "本文未涵盖 X，可作为未来研究方向" |
| "值得深入研究" | 删除，改为具体未来方向 |
| "具有重要意义" | 删除，改为具体贡献描述 |
| "值得进一步探讨" | 改为"本文未涵盖 X（如异质性分析），可拓展" |
| "这可能意味着" | 改为"这表明"或"回归结果显示" |

### 2.5 废话句式类

| AI 典型句式（禁止） | 替代表达（推荐） |
|---------------------|-------------------|
| "首先，我们需要……" | 直接列出步骤 |
| "其次，要……" | 直接说"然后"或"此外" |
| "本文采用XX方法进行实证分析" | 删除，或改为"本节报告基准回归结果" |
| "为了验证上述假说" | 删除，直接说结果 |
| "针对这一问题" | 删除，直接说发现 |
| "在此基础上" | 删除，直接说结论 |

### 2.6 堆砌形容词类

| AI 典型句式（禁止） | 替代表达（推荐） |
|---------------------|-------------------|
| "非常重要的" | 删除，改为具体意义描述 |
| "具有重大意义的" | 删除，改为具体贡献 |
| "极其关键的" | 删除，改为"核心"或"主要" |
| "不可或缺的" | 删除，改为"重要的"或具体描述 |
| "举足轻重的" | 删除，直接说结论 |

### 2.7 被动句过度类

| AI 典型句式（禁止） | 替代表达（推荐） |
|---------------------|-------------------|
| "已经被证实" | 改为"[Author] (Year) 发现" |
| "已经被证明" | 改为"[Author] 提供了证据" |
| "可以被认为" | 删除，改为直接陈述 |
| "可以被视为" | 删除，改为"是"或"反映了" |
| "被认为是一种" | 删除，改为"是" |
| "被发现可以" | 改为"[Author] 发现" |

### 2.8 空洞引用类

| AI 典型句式（禁止） | 替代表达（推荐） |
|---------------------|-------------------|
| "XX研究表明" | "[Author1] 和 [Author2] 发现，X 提升了 Y（β = 0.XX）" |
| "已有学者指出" | "[Author] 指出，[具体观点]" |
| "很多研究认为" | "[Author1; Author2; Author3] 的研究支持" |
| "文献普遍认为" | 删除，直接陈述事实 |

## 三、底气写法规范

### 3.1 底气五要素（结论必须有）

结论和关键发现段落必须满足以下**至少一项**：

| 要素 | 示例 |
|------|------|
| **具体数字** | β = 0.463，95% CI [0.458, 1.596]，p = 0.002 |
| **经济规模** | 占样本均值的 12.3%，相当于每年减少碳排放 50 万吨 |
| **机制描述** | 通过激励绿色技术创新（机制 M），而非调整产业结构（渠道 N） |
| **对比发现** | TR 效应（β = 1.005）是 ESP 效应（β = -0.068）的 14.8 倍 |
| **理论对应** | 与 Porter Hypothesis 的预测一致，即适度环境规制促进创新 |

### 3.2 底气句式对照

**无底气 → 有底气 20 例**：

| 无底气（禁止） | 有底气（推荐） |
|----------------|----------------|
| "研究发现，X 对 Y 有一定影响" | "X 使 Y 平均提升 1.005 个单位（β = 1.005, 95% CI [0.458, 1.596], p = 0.002）" |
| "H1 得到部分验证" | "H1 得到支持：X 显著提升 Y（H1a，β = 1.005, p < 0.01），但对 Z 的影响不显著（H1b，β = -0.068, p = 0.829）" |
| "可能存在异质性" | "效应在大城市是小城市的 1.7 倍（交互项 0.42，p < 0.05），呈现显著规模异质性" |
| "研究结论具有一定的政策启示" | "建议优先在大城市试点：以 1 元财政投入可撬动 3.2 元绿色投资回报" |
| "TR 和 ESP 的效应存在差异" | "TR 的 ATT（1.005，p < 0.01）远大于 ESP 的 ATT（-0.068，p = 0.829），两者差异在 5% 水平上显著（p = 0.024）" |
| "机制分析表明 X 是重要渠道" | "Sobel 检验显示，X 的中介效应占总效应的 34.1%（z = 2.87, p < 0.01），支持 X 作为主要传导渠道" |
| "稳健性检验支持主要结论" | "替换被解释变量后，基准系数从 0.463 变为 0.412，符号和显著性保持不变" |
| "研究结论较为可靠" | "7 项稳健性检验均支持主回归结论：所有检验的系数符号一致，4 项在 5% 水平显著" |
| "存在一定的局限性" | "本文未控制城市层面的政策竞争效应，可能导致 TR 系数高估约 5-10%" |
| "为未来研究提供了方向" | "未来研究可从以下方向拓展：①纳入企业层面微观数据；②考察空间一般均衡效应" |
| "对政策制定有参考价值" | "对发改委的建议：试点推广应优先考虑东部大城市，预期绿色投资乘数效应为 3.2" |
| "研究样本有一定代表性" | "样本覆盖 282 个地级市、4,794 个城市-年观测值，占同期全国地级市的 89%" |
| "变量选取参考了已有研究" | "TR 指标选取参照 Shen et al. (2023a)，该指标已在 iScience 发表并被引用 127 次" |
| "实证结果较为理想" | "基准回归 R² = 0.47，Within R² = 0.12，解释力与同类文献（Lee et al., 2022）相当" |
| "这一发现值得关注" | "这一发现与 Zhang et al. (2024) 在 JEE 上报告的结论一致，但效应量更大（0.463 vs 0.312）" |
| "在不同分组中表现不同" | "分组回归显示，政策效应在东部城市（β = 0.712, p < 0.01）显著，在西部城市（β = 0.089, p = 0.341）不显著，组间差异在 1% 水平上显著" |
| "实证方法较为可靠" | "本文采用 Callaway-Sant'Anna (2021) 的交错 DID 估计量，避免了 Goodman-Bacon (2021) 揭示的 TWFE 偏误" |
| "研究具有一定创新性" | "本文首次将能源系统绩效（ESP）和转型准备度（TR）双维度引入 LCCP 政策评估，填补了现有文献的空白" |
| "上述分析验证了假设" | "表 4-2 的机制检验结果验证了 H2：X 的中介效应占总效应的 34.1%（Sobel z = 2.87, p < 0.01），H2 得到支持" |
| "结论需要谨慎解读" | "由于本文未控制一般均衡效应，TR 系数的政策含义应理解为局部效应而非全国平均效应" |

## 四、表格引导句标准结构

每张表格必须包含以下四要素：

### 4.1 表格前引导句（≥2句）

**第一句：主题句** — 表格报告什么

> 表4-1报告了低碳城市试点对城市转型准备度（TR）、能源系统绩效（ESP）和能源转型指数（ETI）影响的基准回归结果。

**第二句：来源句** — 数据和样本量

> 样本包含282个地级市、4,794个城市-年观测值，时间跨度为2003—2019年，其中2011、2013和2017年三个批次共有70个城市被纳入试点。

**第三句（可选）：核心发现句** — 最关键的数字

> 第(4)列的主回归结果显示，LCCP政策使试点城市的TR指数平均提升1.005个单位，且在1%水平上显著（β = 1.005, p = 0.002）。

### 4.2 表格后解读句（≥1句）

**发现句** — 逐列解读关键系数

> 进一步分析发现，政策对TR的促进作用在政策实施后持续增强，ATT从第1年的0.582逐步上升至第3年的1.247。

**经济意义句**（可选） — 数字的经济含义

> 就经济意义而言，1.005个TR单位的提升相当于样本TR均值（35.730）的2.8%，意味着低碳试点城市在政策实施三年后的转型准备度相对提升了2.8个百分点。

## 五、图表注释解读标准

### 5.1 不合格的图表注释

> "图1 展示了处理组和控制组的 TR 趋势变化"

问题：仅描述"展示了什么"，没有说明"说明了什么"。

### 5.2 合格的图表注释

> "图1 平行趋势检验。纵轴为事件研究法估计的ATT系数，横轴为相对政策实施年份（0为政策实施时点）。
> 处理组（实线）与对照组（虚线）在政策前（t-5至t-1）的TR系数均不显著异于零且置信区间包含0，
> 支持平行趋势假设；政策后（t+1至t+3）处理组系数持续为正且逐步上升，
> 表明LCCP政策显著促进了试点城市的TR提升。"

包含：①图表读法（坐标轴含义）②核心发现（政策前平行、政策后上升）③经济含义（提升幅度）

## 六、机制分析三段式模板

### 标准结构

```latex
\textbf{（一）理论假说}：
[引用理论或文献，说明为什么 M 是潜在传导渠道]

\textbf{（二）实证设计}：
[描述如何检验该机制：中介效应三步法 / 交互项 / 分样本]

\textbf{（三）结果解读}：
[报告核心系数和显著性，结合理论解释机制是否成立]
```

### 典型结果解读句式

**完全中介（X 的效应完全通过 M 传导）**：

> Sobel检验显示，M的中介效应占总效应的34.1%（z = 2.87, p < 0.01），
> 且X的直接效应c'不再显著（β = 0.305, p = 0.068），
> 表明M完全中介了X对Y的影响，H2得到支持。

**部分中介（X 的效应部分通过 M 传导）**：

> Sobel检验显示，M的中介效应占总效应的34.1%（z = 2.87, p < 0.01），
> 且X的直接效应c'依然显著（β = 0.305, p < 0.01），
> 表明M部分中介了X对Y的影响，其中34.1%的效应通过M传导，剩余65.9%为直接效应。

**不成立（X → M 不显著）**：

> 尽管理论预测M是潜在传导渠道，但表4-2显示，X对M的效应不显著（a = 0.089, p = 0.341），
> 可能的原因包括：（1）政策激励的绿色创新集中于少数大企业，掩盖了城市层面的平均效应；
> （2）创新产出的滞后期较长短期内难以观测到显著变化。
> 因此，M并非本文的主要传导渠道。

## 七、批判性文献评述模板

### 7.1 指出研究不足

> 然而，现有研究在[X]方面存在空白：大多数文献仅关注[Y]，
> 未能区分[Z]的异质性效应（Author1, Year; Author2, Year）。
> 具体而言，[Author1] (Year) 虽然发现……，但其实证设计存在以下局限……

### 7.2 对比理论预测

> 与Porter Hypothesis的预测一致，环境规制通过激励绿色技术创新提升了环境绩效（β = 0.XX, p < 0.01）。
> 然而，[Author] (Year) 的研究得出了相反结论，其可能的解释是……

### 7.3 指出方法局限

> 已有研究多采用OLS估计，未能解决内生性问题（Author, Year）：遗漏变量偏差可能导致系数高估约20-30%。
> 为此，本文采用双重差分法并辅以熵平衡控制选择偏差……

### 7.4 强调本文价值

> 本文首次在[新维度/新数据/新方法]上填补了这一空白：
> 一是构建了TR和ESP双维度政策评估框架，
> 二是利用交错DID（Callaway-Sant'Anna, 2021）解决了处理时间异质性问题，

## 九、写作自检流程

每次生成章节后，按以下顺序自检：

```
Step 1: 扫描 AI 味关键词
  → 全文搜索本文档第二部分的 20+ 个 AI 典型句式
  → 发现任何一项，立即重写对应句子

Step 2: 评估结论底气
  → 结论段是否包含具体数字、经济规模、机制描述或对比发现？
  → 没有任何一项，立即重写结论段

Step 3: 检查表格引导句
  → 每张表格前是否有 ≥2 句引导（主题句 + 来源句）？
  → 每张表格后是否有 ≥1 句解读？
  → 任何一项不满足，补充或重写

Step 4: 检查图表注释
  → 每张图的注释是否包含"说明什么"（而不仅是"展示什么"）？
  → 是否包含具体数字或对比描述？
  → 任何一项不满足，重写图表注释

Step 5: 段落数检查
  → 每章段落数是否达到最低要求（见上表）？
  → 不满足，扩充内容或拆分章节

Step 6: 自动化验证（可选）
  → python scripts/paper_language_checker.py paper.tex
  → 查看得分和详细问题列表
```
