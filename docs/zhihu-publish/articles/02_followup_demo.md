# 我把一篇顶刊 DID 实证，交给开源 Agent 跑了一遍：省下 3 个月，也认清了 AI 的 3 个边界

> 一句话总结：告诉它研究主题，它帮你从文献综述 → 实证设计 → 数据获取 → DID 估计 → LaTeX 草稿一路跑通。但署名的是你，因果推断的责任也是你的。

上一篇我介绍了自己做的开源项目 **FinResearch Agent**（一个面向经济金融研究的端到端 AI 工作流）。评论区问得最多的一句话是：

> "听起来很美，但真跑起来到底行不行？"

这篇不讲理念，只讲一次**真刀真枪的复现记录**。我拿它复现了一个典型的实证任务——「低碳城市试点对企业绿色转型的影响」，一个标准的**交错双重差分（Staggered DID）**设计。完整跑完 8 步流水线，实际产出：一份约 5,000 字的 LaTeX 草稿、4 张图表、40 多条引文。

跑通的部分我一句带过，重点讲**踩的 3 个坑**，以及一个比"能不能用"更重要的问题：**AI 到底能替研究者干什么，不能干什么。**

---

## 一、先交代背景：这次复现的完整设置

为了让结论有说服力，先把实验设置摊开：

| 项目 | 设置 |
|------|------|
| 研究问题 | 低碳城市试点（分批推行）对企业绿色转型的影响 |
| 识别策略 | 交错 DID（多期多批次处理） |
| 样本 | A股上市公司 2010–2023 年面板 |
| 处理变量 | 企业所在城市是否/何时进入试点名单 |
| 结果变量 | 绿色专利、绿色投资强度 |
| 目标期刊风格 | 国内经济学 C 刊 / 国际 field journal |

选这个题目不是随便挑的——**交错 DID 是过去五年计量领域"翻车"最集中的地方**。2021 年之后一连串论文（Goodman-Bacon、Callaway-Sant'Anna、Sun-Abraham、de Chaisemartin-D'Haultfœuille）都在说同一件事：**传统双向固定效应（TWFE）在交错处理下会得到有偏、甚至符号相反的估计**。这正是检验一个"AI 研究工具"是不是玩具的好试金石——它到底懂不懂这些坑。

---

## 二、跑通的部分（省下的时间最实在）

这几步基本是"开机自动完成"，我几乎没插手：

**1. 文献综述与引文网络**
输入主题后，它检索并整理了 40 多篇相关文献，自动构建了引文网络，标出了"低碳城市 + 绿色创新"这个交叉点上被引最多的几篇奠基文献，以及最近三年的新工作。这一步我原来手动做，至少两三天，还容易漏掉关键文献。

**2. 数据获取与面板拼接**
它调用数据接口，把 A股财务数据和城市层面统计自动拼成一张平衡面板，处理了缺失值标记、变量对齐、试点名单与城市代码的匹配。省去了我反复在 Excel 里 VLOOKUP 的时间。

**3. 实证分析一次成型**
标准 DID、Goodman-Bacon 分解、平行趋势检验、事件研究图——一次跑完，图表直接出成 300 DPI 的成品。

**4. LaTeX 初稿**
套用期刊模板，生成了带章节结构、交叉引用、BibTeX 参考文献的可编译 LaTeX 草稿。

这部分没什么好吹的，工具该做的它做到了。**真正值钱的经验，在下面三个坑里。**

---

## 三、坑 1：免费数据源的粒度，配不上顶刊的精度

我一开始图省事，用了免费兜底数据源（不想先花钱买付费数据库）。行情和主要财务字段都没问题，但**分行业、分年度的细粒度变量**明显不够——有些细分行业直接缺值，有些年份的统计口径对不上，绿色专利的分类还需要额外映射。

这不是工具的锅，是数据本身的现实：**免费能给你 80% 的覆盖，但顶刊要的是最后那 20% 的精度。**

**我的解决办法**：先用免费源把整条流水线跑通、确认 idea 站得住、主效应方向明确，**再针对性地补几个关键变量的付费数据**。

**给硕博生的实操建议**：先验证，后投入。工具能把流程从几个月压缩到几天，但数据质量的钱省不掉——只是你可以把这笔钱花得更准，而不是一上来就买一堆最后没用上的库。

---

## 四、坑 2：标准 DID 显著，不代表因果站得住（这是核心）

DID 跑完，主回归系数漂亮又显著，我差点就截图发朋友圈了。

但 **Goodman-Bacon 分解**给我泼了盆冷水：分解结果显示，相当一部分估计权重来自 **"早处理组 vs 晚处理组"** 的比较。熟悉交错 DID 的都知道，这正是 TWFE 最经典的偏误来源——**用已经受过处理的组当对照组，会把动态处理效应"污染"进估计量**。

换句话说，那个显著的系数里，混进了不该有的比较。**如果我直接拿它去投稿，审稿人一句"你有没有做 Bacon 分解"就能让我原地爆炸。**

**解决**：换成 **Callaway & Sant'Anna (2021)** 估计量重跑，只用"从未处理组"和"尚未处理组"作对照。结果方向一致，但幅度更保守、也更干净。我又补跑了 Sun-Abraham (2021) 做交叉验证，两者结论一致，这才敢确认主效应成立。

这一步工具帮了大忙——**5 种现代估计量它全都实现好了**，我要做的只是判断"该换哪个、为什么换"。

**但这恰恰是 AI 救不了你的地方**：它能把 5 种估计量都跑给你看，甚至能提示你"Bacon 分解显示存在坏对照组"，但**"标准 DID 的结果为什么不能信、最终该信哪个、怎么跟审稿人解释"——这个判断链条必须你自己走完。** 识别策略是研究者的核心价值，工具只是把计算成本降到了零。

---

## 五、坑 3：字段命名对不上，语义核对还得靠人

论文和数据库之间永远隔着一层"命名鸿沟"。比如全要素生产率，文献里写 `TFP_OP`（Olley-Pakes 法），数据库里可能叫 `TFP_OP_LP`、`TFP_LP` 或者别的后缀——**差一个字母，测的可能是完全不同的东西。**

工具自动生成了字段映射表，覆盖了大部分变量，但我仍然逐个核对了几个关键变量的定义。**这几分钟省不得**：映射错一个核心变量，后面整条链路全白跑，而且这种错误在最终结果里往往看不出来，是最危险的那种。

**结论**：自动化能把"体力活"压到最小，但凡是涉及"这个字段到底对不对、测的是不是我要的概念"这种**语义判断**，人必须留在环里。

## 六、一张表看清：AI 干了什么，我干了什么

| 环节 | AI 自动化 | 我人工把关 |
|------|:---:|:---:|
| 文献检索 + 引文网络 | ✅ 全自动 | 抽查相关性 |
| 数据拼表 + 面板对齐 | ✅ 全自动 | 校验字段映射语义 |
| 跑 DID / Bacon / 平行趋势 | ✅ 全自动 | — |
| 选哪个估计量 | 提供 5 种选项 + 诊断 | ✅ **我决定** |
| 判断结果可不可信 | 给诊断信号 | ✅ **我决定** |
| LaTeX 草稿 | ✅ 全自动 | 逐字审阅后才敢投 |

一句话概括：**AI 负责"跑"，我负责"判断"。**

它把一篇实证从三个月压缩到几天，但**它压缩的是计算和检索的成本，不是思考的成本**。署名的是我，因果推断成不成立的责任，也是我的。任何号称"AI 全自动写论文、你只要点一下"的说法，要么是没做过实证，要么是在骗流量。

---

## 七、给经管硕博生的 4 条建议

1. **别跳过 Bacon 分解**：标准 DID 显著 ≠ 真实因果效应。先看权重来源，再决定信不信那个系数。
2. **交错处理优先用现代估计量**：CS(2021) / Sun-Abraham(2021) / dCdH，比 TWFE 稳健得多。多个估计量结论一致，才是硬结论。
3. **先用免费源验证 idea，再花钱买数据**：把试错成本压到最低，钱要花在刀刃上。
4. **把 AI 当"超级 RA"，不是"代笔"**：让它干检索、拼数据、跑回归、排版这些体力活，把你自己的时间留给 idea、识别策略和结果解读——这些才是研究者不可替代的部分。

---

## 八、写在最后

我做这个项目，不是想证明"AI 能取代研究者"，恰恰相反——**跑完这一遍，我比以前更确信研究者的核心价值在哪：不是重复劳动，是判断力。**

工具的意义，是把你从三个月的体力活里解放出来，让你有时间去想那些真正重要的问题：这个识别干净吗？这个机制讲得通吗？这个结论敢下吗？
