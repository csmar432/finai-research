## 正文

上个月我把 FinResearch Agent 跑了一遍真实的论文复现任务，选的是 **JFE 2024** 一篇用 DID 研究"低碳城市试点对企业出口的影响"的论文。

完整跑下来 8 步流水线，**真实产出 5,000 字 LaTeX、4 张图表、48 条引文**，但过程中踩了 3 个坑，今天分享出来。

---

### 🟢 跑通的部分

```
✅ 自动化完成的事：
- 找主题相关文献 48 篇，整理引文网络（原本要 2 天）
- 自动下载 Tushare A股财务数据 + 城市统计年鉴
- 跑标准 DID / Bacon 分解 / 平行趋势检验
- 生成可投稿的 LaTeX 草稿
```

### 🔴 踩的 3 个坑

**坑 1：免费数据源精度不够**

我用的是 yfinance 兜底（不花 Tushare 的钱），但分行业数据粒度差强人意。
**解决**：后来切到 CSMAR 的免费 demo 接口（精度够用，就是稍微慢）。

**坑 2：Bacon 分解识别到"坏对照组"**

DID 跑完后 Bacon 分解显示有 30% 权重来自"早期处理 vs 后期处理"——这是已知的偏误来源。
**解决**：手动换成 **Callaway-Sant'Anna (CS 2021)** 估计量，结果稳健了很多。

**坑 3：CSMAR 字段命名和老论文不一致**

JFE 论文里写的是 `TFP_OP`，CSMAR 实际叫 `TFP_OP_LP`。
**解决**：脚本自动生成了字段映射表，但仍需人工核对 5 个字段。

### 💡 给出 3 个对经管硕博生的建议

1. **不要跳过 Bacon 分解**：标准 DID 显著 ≠ 真实因果效应
2. **优先用现代估计量**：CS / Sun-Abraham 处理异质性更稳健
3. **跑流水线前先看依赖**：mypy / pytest / OpenSSF 通过率决定项目可信度
