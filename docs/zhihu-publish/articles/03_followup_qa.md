## 回答模板 1：通用版

> 问题：AI 写经济学论文靠谱吗？

**简短回答**：能用，但必须人工核实。

我现在用 FinResearch Agent（一个开源项目）跑过 5+ 篇论文复现，结论是：

✅ **AI 擅长的**：
- 文献综述（找论文 + 整理引文网络）
- 数据获取（跨数据库整合）
- 标准化实证（DID / IV / PSM）
- LaTeX 模板套用

❌ **AI 不擅长的**：
- 研究 idea 的新颖性判断
- 识别策略的合理性论证
- 理论机制的故事化阐释
- 顶刊偏好的风格把控

**最实用的用法**：把 AI 当研究助理，让它跑数据 + 套模板，**idea 和识别策略仍由你决定**。

## 回答模板 2：工具推荐版

> 问题：有没有开源的论文写作工具？

推荐一个我自己在用的：**FinResearch Agent**（GitHub 上 11 stars，MIT 协议）。

它的特点是：
- **数据源多**：43 个 MCP 服务器（Tushare / Wind / CSMAR / yfinance / SEC EDGAR）
- **方法全**：47 种因果识别方法（覆盖 JF / JFE / RFS / 经济研究）
- **工程化**：12,520 个 pytest 测试 + OpenSSF Gold 21/21
- **可投稿**：直接生成 LaTeX 草稿 + 期刊模板

但**严肃建议**：AI 草稿必须人工核实，**它帮你跑数据，不帮你想 idea**。

GitHub：https://github.com/csmar432/finai-research

## 回答模板 3：研究生效率版

> 问题：研究生如何用 AI 提高效率？

我读研期间用 AI 工具的 3 个原则：

1. **数据脏活累活全交给 AI**：找文献、跑数据、套模板
2. **idea 永远自己抓**：AI 给的 idea 99% 已被抢发
3. **结果必须人工核实**：AI 会编造统计量、引文、方法细节

实操流程（每周省 10 小时）：
- 周一：让 AI 找 50 篇相关文献，整理引文网络
- 周二：跑数据 + 标准化模型
- 周三：自己写识别策略部分
- 周四：AI 套 LaTeX 模板
- 周五：人工 review 全稿

工具清单（开源优先）：
- **FinResearch Agent**：43 MCP + 47 方法 + 88 期刊模板
- **Zotero**：文献管理
- **Overleaf**：LaTeX 写作
- **Stata / Python**：实证分析
