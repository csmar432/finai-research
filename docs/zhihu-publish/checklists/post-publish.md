# 发文后 24 小时行动清单（D1 周一全天）

> **核心原则**：每条评论都要回复，每条私信都要回答
> **关键时刻**：T+1h / T+3h / T+6h / T+12h / T+24h

---

## T+0（发布后立刻）

- [ ] 自己顶一条评论（置顶评论模板见 pre-publish.md）
- [ ] 截图保存：发布成功的页面（备用）
- [ ] 复制文章链接备用

## T+1h（10:30）

- [ ] 回复前 5 条评论（每条 50-100 字，**不要复制粘贴**）
- [ ] 检查有没有负面评论需要处理
- [ ] 把文章链接发到自己的微信朋友圈（限可见）

## T+3h（12:30）

- [ ] 继续回复评论（目标 T+3h 回复 15 条）
- [ ] 把文章同步到知乎专栏（增加曝光）
- [ ] 转发到 2-3 个核心微信群（学术群 / AI 群 / 开源群）

## T+6h（15:30）

- [ ] 统计阅读量、点赞、收藏数据
- [ ] 在文章末尾"更新于"加一行："发布 6h，数据：X 阅读 / Y 赞 / Z 收藏"
- [ ] 继续回复评论

## T+12h（21:30）

- [ ] 晚间互动高峰，每条新评论都要回复
- [ ] 邀请 3-5 位朋友点赞（**不要用机器人**）
- [ ] 准备明天 D2 的跟进 1 文案

## T+24h（D2 周二 9:30）

- [ ] 24h 数据复盘：阅读量 / 点赞 / 收藏 / Star 增量
- [ ] 填写 `KPIs.md` 表格
- [ ] 发布 D2 跟进 1（`articles/02_followup_demo.md`）
- [ ] 写一段"发布 24h 复盘"贴到评论区（增加互动）

## 互动回复模板

### 正面评论（"很好用"、"想试试"）

```
感谢支持！跑流程时遇到任何问题，欢迎在 GitHub 提 issue：
https://github.com/csmar432/finai-research/issues

我会 24h 内回复。如果你想看某个具体场景的演示，告诉我你的研究方向。
```

### 提问类评论（"怎么用 X 功能"）

```
[这里填具体回答，50-100 字]

更详细的使用方法可以看 README：
https://github.com/csmar432/finai-research/blob/main/README.md
```

### 质疑类评论（"AI 写论文不靠谱"）

```
完全同意。AI 永远不能替代研究者的判断。

这个工具的定位是"研究助理"——帮你跑数据、套模板，但 idea 和识别策略
仍由你决定。草稿必须人工审阅后才能投稿，这点在 README 里也写清楚了。

如果你觉得某部分"过度自动化"，欢迎告诉我具体场景，我看看怎么调整。
```

### 错误信息类（"跑不起来"）

```
收到，请直接去 GitHub 提 issue：
https://github.com/csmar432/finai-research/issues/new

附上：
1. 你的操作系统 + Python 版本
2. 完整报错信息（截图）
3. 你跑的命令

我会 24h 内回复并修复。
```

### 纯表情 / 无意义评论

- 点赞即可，无需回复

---

## 不要做的事

❌ 跟黑子对线（拉黑即可）
❌ 复制粘贴相同的回复（会被知乎降权）
❌ 频繁修改文章（每次修改都会重新计算权重）
❌ 提交给"想法"（降权）
❌ 在评论区贴第三方联系方式（违规）

---

## 应急情况

| 情况 | 处理 |
|------|------|
| 阅读量 < 100 | 检查是否违规词，必要时改标题 |
| 评论区被攻击 | 锁评论区，不对线 |
| GitHub 被灌水 | 立刻关闭 issue，回复"已记录" |
| 工具被打 1 星 | 在 GitHub 公开回复 issue，不删评 |
