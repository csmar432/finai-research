## 关键转化漏斗

```
知乎阅读 (500)
  ↓ 25% 点击 GitHub (125)
    ↓ 10% Star (12)
      ↓ 5% Fork (1)
        ↓ 2% 提 Issue (0.5)
```

**目标**：500 阅读 → 12 Star → 1 Fork → 1 Issue

> **提示**：60% 的 GitHub Star 来自知乎跳转，所以**主文必须放链接**。
