# fin-submit-check — 投稿前检查

根据 `PAPER_OUTLINE.md` 中的目标期刊要求，逐一检查论文的格式、图表、引用、参考文献、数据可用性等所有投稿必需项，以及文字质量（AI 味、底气、表格引导句）。

## 功能

### 检查项（12 大类）

| 检查项 | 说明 |
|--------|------|
| 匿名检查 | 双盲审稿匿名性（作者信息、致谢、资助信息）|
| 字数/格式 | 目标期刊字数限制、格式规范 |
| 图表分辨率 | ≥300 DPI，EPS/PDF 格式 |
| 引用完整性 | 无空白引用、无未核实引用 |
| 参考文献格式 | JF/JFE/RFS/GB-T-7714 等 |
| 公式编号 | 全文编号连续且无遗漏 |
| 数据可用性 | 数据集说明、代码可用性 |
| 附录检查 | 互联网附录完整性 |
| 语法校对 | Academic Proofreading |
| LaTeX 编译 | 无编译错误、无警告 |
| **语言质量** | AI 味检测、底气检测、表格引导句、图表注释 |
| **缩略语规范** | 首次出现是否写全称 |

### PDF 自动化验证

- 图表 DPI 检查（Python 脚本）
- 引用审计（正则表达式）
- 编译错误扫描
- **AI 味检测**：`python scripts/paper_language_checker.py paper.tex`
- **底气检测**：结论段是否包含具体数字或机制描述

## 语言质量检查清单（新增）

### AI 味自检（10 题，全部通过才算合格）

| # | 检查项 | 检测方法 |
|---|--------|----------|
| 1 | 全文无"值得注意的是" | 搜索关键词 |
| 2 | 全文无"综上所述" | 搜索关键词 |
| 3 | 全文无"在一定程度上" | 搜索关键词 |
| 4 | 全文无"近年来" | 搜索关键词（替换为具体年份） |
| 5 | 全文无"可能存在" | 搜索关键词 |
| 6 | 全文无"有待进一步研究" | 搜索关键词 |
| 7 | 全文无"首先我们需要" | 搜索关键词 |
| 8 | 全文无"具有重大意义" | 搜索关键词 |
| 9 | 全文无"已经被" | 搜索关键词（替换为作者+年份） |
| 10 | 全文无空洞引用（无具体发现的"XX研究表明"） | 手动检查 |

### 底气自检（5 题，全部通过才算合格）

| # | 检查项 | 标准 |
|---|--------|------|
| 1 | 结论段包含具体数字 | β = X.XXX，p = X.XXX |
| 2 | 结论段包含经济规模描述 | 占均值 X% / 相当于 X 亿元 |
| 3 | 机制分析包含渠道对比 | 通过 X 渠道，而非 Y 渠道 |
| 4 | 异质性分析包含倍数描述 | A 是 B 的 X 倍 |
| 5 | 主要发现包含理论对应 | 与 X 假说一致/相反 |

### 表格引导句自检

| # | 检查项 | 标准 |
|---|--------|------|
| 1 | 每张表格前有主题句 | ≥1 句 |
| 2 | 每张表格前有来源句 | 含样本量和时间范围 |
| 3 | 每张表格后有解读句 | ≥1 句含具体数字 |
| 4 | 表格标题精炼 | ≤15 字 |

### 图表注释自检

| # | 检查项 | 标准 |
|---|--------|------|
| 1 | 每张图有 caption | 含图表编号 |
| 2 | caption 包含"说明什么" | 而非仅"展示什么" |
| 3 | caption 包含具体数字 | 系数、百分比或倍数 |
| 4 | 坐标轴含义明确 | X/Y 轴含义清楚 |

## 快速检查命令

```bash
# AI 味自动检测
python scripts/paper_language_checker.py paper.tex

# 批量检测（目录）
python scripts/paper_language_checker.py output/fin-manuscript/draft_v1/ --batch

# 引用完整性检查
python scripts/check_bib.py paper.tex references.bib

# LaTeX 编译检查
python scripts/check_latex.sh paper.tex
```
